Negative cases observed before their fixes:

- Initial implementation: all four initial end-to-end tests failed before the CLI existed.
- A real PTY test rejected the first macOS `script` transport with `tcgetattr/ioctl: Operation not supported on socket`; the transport was replaced with node-pty.
- Restoring old exclusion rules deleted a newly excluded file during rollback; the test failed with `An excluded file was deleted during restore or rollback.` The current exclusion configuration is now always retained.
- Escape was buffered instead of forwarded; the byte-invariance test failed. The input gate now forwards Escape immediately while recognizing paste boundaries across chunks.
- Plain `npm install --global .` linked a clean checkout without its PTY dependency. The documented `--install-links` command installed the dependency, and the installed CLI passed the PTY test.

A single local timing sample with 2,000 distinct files, approximately 2 MiB total: initial checkpoint **472 ms**, unchanged checkpoint **194 ms**, undo of one edited file **416 ms**. These are not cross-platform performance guarantees.

Not verified: live authenticated sessions with the named coding agents, remote CI execution, Linux runtime behavior, x64 runtime behavior, power-loss recovery, network filesystems and hostile concurrent writers. CI is configured for macOS and Ubuntu on Node 22 and 24. The PTY test uses Python 3 as a test driver; runtime use does not require Python.
